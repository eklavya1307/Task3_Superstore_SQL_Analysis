# Task 3: Superstore SQL Analysis Using Subqueries, CTEs, and Window Functions

## Overview

This project analyzes the Superstore dataset using SQL concepts such as Subqueries, Common Table Expressions (CTEs), Window Functions, and Joins. The objective is to transform raw sales data into meaningful business insights by identifying top customers, analyzing customer sales performance, ranking customers, and visualizing key findings.

---

## Objective

Analyze sales data using SQL by applying:

* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* Joins

to solve business queries and generate customer sales insights.

---

## Dataset

**Dataset Used:** Superstore Dataset

The dataset contains information related to:

* Customers
* Orders
* Products
* Sales
* Profit
* Quantity
* Categories and Sub-Categories

### Orders Table

Contains order-related information.

### Products Table

Contains product-related information.

Data was inserted using:

* Table creation from the raw dataset

---

## Step 2: SQL Analysis

### Query 1 - Orders Above Average Sales

Identified orders whose sales value exceeded the overall average sales.

### Query 2 - Highest Sales Order Per Customer

Retrieved the highest sales order placed by each customer.

### Query 3 - Total Sales Per Customer

Calculated total sales generated by every customer.

### Query 4 - Customers Above Average Total Sales

Identified customers whose total sales exceeded the average customer sales.

### Query 5 - Customer Sales Ranking

Ranked customers according to their total sales using Window Functions.

### Query 6 - Order Row Number By Customer

Assigned row numbers to orders within each customer group using PARTITION BY.

### Query 7 - Top 3 Customers By Sales

Displayed the top-performing customers based on total sales.
